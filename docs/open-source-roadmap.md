# 开源路线与产品放大

定位：让官方视频 API 或自有视频算力，变成电商内容生产流程。可复用资产是商品事实约束、编导、模型适配、任务恢复、质检和剪辑，使用者提供 API 额度或算力。

本轮落地：默认 MiniMax H3 / H3 Max 官方 V2 API，无需本地部署模型，保留可选 ComfyUI；网页单次创作、本机智能体接口、横竖版和多 SKU 批量调用；兼容文本模型和按引擎安装自检；无私密值模板、源码白名单、历史审计和隔离测试。尚未用真实付费 API 验收生成质量。

| 后续优先级 | 尚未实现的能力 | 验收方式 |
| --- | --- | --- |
| P1 | 跨品类脚本与可选人工审批 | 候选稿、确认记录、事实约束测试 |
| P1 | 质检失败硬阻断与重拍预算 | 二次不合格禁止交付，记录误报率 |
| P1 | 社区公开可得的视频模型适配 | 权重/节点许可、硬件基准、完整成片 |
| P2 | 同份生成镜头多渠道剪辑 | 无需重复 GPU 生成即可输出不同版式 |
| P2 | 多 GPU 调度和成本上限 | 并发、取消、幂等、恢复与预算实测 |
| P3 | 团队商用部署 | 登录授权、配额、TLS、审计、租户隔离 |

优先验证有自有素材的电商工作室（云 API 或闲置 GPU），衡量每条**人工验收通过的成片**的耗时与成本。可用工作流适配、部署支持、模板开发验证服务需求；本轮未加入计费、会员或未实现能力的宣传。
